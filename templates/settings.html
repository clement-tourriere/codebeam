Remote auto-indexing

Periodically re-pull and reindex your selected remote repositories (GitHub, GitLab, self-managed GitLab) so their search stays fresh — no manual reindex needed. Works for on-prem hosts that can't reach Codebeam, since it polls outward. Local repositories are kept fresh automatically by the file watcher.

Inaccessible repositories

When a remote repository fails to index because your token can't read it (for example a GitLab project you're no longer a member of), drop it from your selection so the auto-refresher stops retrying it. You can re-select it later once access is restored.
